# iOS ショートカット設定ガイド（YPT for me）

NFC タグに iPhone をかざすと、**勉強の開始 / 終了が記録される**ようにする手順書です。
ショートカットを触ったことがなくても作れるように、**3段階**に分けています。

| 段階 | できること | 難易度 |
| :--- | :--- | :--- |
| **基本版**（Step 0〜2） | かざすと開始 / 終了。カテゴリは前回と同じ | ★ アクション3個 |
| **完全版**（Part A） | ＋ カテゴリを選べる / 場所を記録 / 集中モード連動 | ★★ |
| **オフライン対応**（Part B） | ＋ 電波がなくても記録して、あとで自動送信 | ★★★ |

**基本版が動いてから**、次の段階に進んでください。段階ごとに別のショートカットとして作り、動作確認してから NFC オートメーションの呼び出し先を切り替えるのが安全です。

> [!NOTE]
> iOS の画面表示やアクション名は、OS のバージョンで少し違うことがあります。「それっぽい名前のもの」を検索して選んでください。

---

## Step 0. 用意するもの

| 名前 | 値 |
| :--- | :--- |
| ベースURL | `https://ypt-for-me.vercel.app` |
| `API_SECRET` | あなたが Vercel に登録した文字列 |

### （任意）PC で先に動作テスト

PowerShell で次を実行します（`ここにAPI_SECRET` を自分の値に置き換え）。

```powershell
Invoke-RestMethod -Method Post -Uri "https://ypt-for-me.vercel.app/api/study/toggle" -Headers @{ Authorization = "Bearer ここにAPI_SECRET" }
```

`message : 開始しました：...` と出れば成功です。**実際に開始されるので、もう一度実行して終了してください。**

## Step 1. 基本版ショートカット「YPT」を作る（アクション3個）

1. **「ショートカット」アプリ** → 下のタブ「ショートカット」 → 右上 **「＋」**
2. 画面上部の名前を押して **「YPT」** に変更

### アクション 1：URLの内容を取得
1. 「アクションを検索」に `URL` → **「URLの内容を取得」**
2. 青い「URL」を押して `https://ypt-for-me.vercel.app/api/study/toggle` を入力
3. 「**›**」（矢印）で詳細を開き、**方法** を **`POST`** に変更
4. **ヘッダ** → **「新規ヘッダを追加」**
   - キー: `Authorization`
   - テキスト: `Bearer ` + あなたの `API_SECRET`（**`Bearer` の後ろに半角スペース**）

### アクション 2：辞書から値を取得
1. 検索で `辞書` → **「辞書から値を取得」**
2. 「辞書」が **「URLの内容」** になっていることを確認
3. 「キー」に `message` と入力

### アクション 3：通知を表示
1. 検索で `通知` → **「通知を表示」**
2. 本文が **「辞書の値」** になっていることを確認

▶ を押して、1回目は「開始しました」、2回目は「お疲れ様！…」と出れば成功です。

---

## Step 2. NFC タグに割り当てる

1. 下のタブ **「オートメーション」** → 右上 **「＋」** → **「NFC」**
2. **「スキャン」** を押し、タグに iPhone の上部をかざす
3. 名前を付ける（例: `PCパームレスト`）→ **「OK」** → **「次へ」**
4. **「新規の空のオートメーション」** → **「ショートカットを実行」** を追加
5. 青い「ショートカット」を押して **「YPT」** を選ぶ
6. **「次へ」** → **「実行前に確認」を OFF**（「即座に実行」）→ **「完了」**

> **ポイント:** 画面が真っ暗だと NFC が反応しません。サイドボタンを1回押して画面を点けてからかざしてください（ロック解除は不要）。

### タグ名を渡す（完全版で使います）

完全版では、**どのタグを使ったか**（PC か ICOCA か）を記録できます。Step 2 の手順 4 で、**「テキスト」** アクション（中身 `pc_palmrest`。ICOCA なら `icoca_main`）を **「ショートカットを実行」の前に** 置き、実行するショートカットの **入力** にそのテキストを渡してください。

# Part A. 完全版（カテゴリ選択・場所・集中モード）

## A-0. 事前準備

1. **集中モード「勉強」を作る**
   `設定` → `集中モード` → `＋` → `カスタム` → 名前を **「勉強」** にして作成
   （通知を許可するアプリは最小限にしておくと集中しやすいです）
2. **位置情報の許可**
   `設定` → `プライバシーとセキュリティ` → `位置情報サービス` → `ショートカット` → **「Appの使用中は許可」** 以上
   （正確な位置情報も ON）

## A-1. 流れ（先に全体像）

```
タグにかざす
 ├─ 準備：ベースURL・認証・タグ名を変数に入れる
 ├─ サーバーに状態を聞く（status）
 ├─ 勉強中？
 │    ├─ はい → 終了（toggle）→ 通知 → 集中モードOFF
 │    └─ いいえ → カテゴリを選ぶ → 現在地を取得 → 開始（start）→ 通知 → 集中モードON
```

## A-2. ショートカット「YPT 完全版」を作る

新しいショートカットを作り、名前を **「YPT 完全版」** にします。以下を **上から順に** 追加してください。

> **「変数に設定」の使い方:** 直前のアクションの結果に名前を付ける機能です。検索で `変数` → **「変数に設定」**。青い「変数名」を押して名前を入力します。以降のアクションで、その名前の変数を選んで使えます。

### ① 準備
1. **「ショートカットの入力」**（アクション検索で `入力`）を **「変数に設定」** → 名前 `タグ`
   > 手動で▶実行した時は入力が空です。空でも動きます（タグ名が記録されないだけ）。
2. **「テキスト」** に `https://ypt-for-me.vercel.app` → **「変数に設定」** → 名前 `BASE`
3. **「テキスト」** に `Bearer ` + `API_SECRET`（半角スペース）→ **「変数に設定」** → 名前 `認証`

### ② 今の状態を聞く
4. **「URLの内容を取得」**
   - URL: `BASE` 変数 + `/api/study/status`（テキストの中に変数を差し込みます）
   - 方法: `GET`
   - ヘッダ: `Authorization` = `認証` 変数
5. **「変数に設定」** → 名前 `状態`
6. **「辞書から値を取得」**: `状態` から、キー **`active_session`** を取得

### ③ 分岐
7. **「もし」**: 手順 6 の「辞書の値」**「値を持っている」**
   > 勉強中のときだけ `active_session` が入っています。「値を持っている」が選べない時は「空ではない」に近い項目を選んでください。

#### ▼ 勉強中だった場合（終了）
8. **「URLの内容を取得」**
   - URL: `BASE` + `/api/study/toggle?tag_id=` + `タグ`
   - 方法: `POST`
   - ヘッダ: `Authorization` = `認証`
9. **「辞書から値を取得」**: キー `message`
10. **「通知を表示」**: 辞書の値
11. **「集中モードを設定」**: 「勉強」を **オフ**

#### ▼ 「そうでなければ」（開始）
12. **「辞書から値を取得」**: `状態` から、キー **`categories`**
13. **「それぞれを繰り返す」**（検索 `繰り返す`）→ 入力はそのまま
    - 中に **「辞書から値を取得」**: 「繰り返しアイテム」からキー **`name`**
    - 繰り返しを閉じる（End Repeat）
    > これでカテゴリ名だけのリストができます。
14. **「リストから選択」**: 入力は **「繰り返しの結果」**
15. **「変数に設定」** → 名前 `カテゴリ名`
16. **「現在地を取得」**
17. **「現在地の詳細を取得」**: 項目 **「緯度」** → **「変数に設定」** → 名前 `緯度`
18. **「現在地の詳細を取得」**: 項目 **「経度」** → **「変数に設定」** → 名前 `経度`
19. **「URLの内容を取得」**
    - URL: `BASE` + `/api/study/start`
    - 方法: `POST`
    - ヘッダ: `Authorization` = `認証`
    - 要求本文: **JSON**。「新規フィールドを追加」で次を入れる

| キー | 型 | 値 |
| :--- | :--- | :--- |
| `category_name` | テキスト | `カテゴリ名` 変数 |
| `tag_id` | テキスト | `タグ` 変数 |
| `latitude` | 数字 | `緯度` 変数 |
| `longitude` | 数字 | `経度` 変数 |

20. **「辞書から値を取得」**: キー `category_name`
21. **「通知を表示」**: `開始しました：` + 辞書の値
22. **「集中モードを設定」**: 「勉強」を **オン**、**「オフにするまで」**
23. 最後に **「もし」を閉じる**（End If）

### A-3. 動作確認
▶ を押して、次を確かめます。
- 1回目: カテゴリが選べる → 「開始しました」→ 集中モードがオンになる
- 2回目: 「お疲れ様！」→ 集中モードがオフになる
- https://ypt-for-me.vercel.app の画面で、場所の表示が入っていること

問題なければ、NFC オートメーション（Step 2）の呼び出し先を **「YPT 完全版」** に変更します。

# Part B. オフライン対応（電波がなくても記録する）

> [!WARNING]
> この部分はショートカットの機能に依存する箇所が多く、**ここに書いた手順は実機で未検証**です。つまずいた箇所があれば、その画面を教えてください。

## B-1. 考え方

iOS のショートカットには「通信エラーを受け止める」機能がありません。そこで順番を逆にします。

```
かざす
 1. まず iPhone の中に「記録」をファイルとして保存（電波不要）
 2. そのあと、たまっている記録をサーバーに送る
     └ 電波がなくて失敗しても、記録は残っている → 次回にまとめて送られる
```

- 開始か終了かは、**iPhone の集中モード「勉強」がオンかどうか**で決めます（サーバーに聞かないため）
- 記録 1 件 = ファイル 1 個。送信に成功したら、そのファイルを削除します

## B-2. 準備（1回だけ）

1. 「ファイル」アプリ → **iCloud Drive** → **ショートカット** フォルダの中に、`ypt-for-me` フォルダを作る
2. その中に `pending`（未送信の記録）フォルダを作る
3. **カテゴリ一覧の保存用ショートカット**を作る（次の B-3）

## B-3. 小さなショートカット「YPT カテゴリ更新」

オフラインでもカテゴリを選べるように、カテゴリ名を iPhone に保存しておきます。

1. **「URLの内容を取得」**: `GET https://ypt-for-me.vercel.app/api/study/status`（ヘッダ `Authorization` = `Bearer API_SECRET`）
2. **「辞書から値を取得」**: キー `categories`
3. **「それぞれを繰り返す」**: 中で **「辞書から値を取得」**（キー `name`）
4. **「テキストを結合」**: 入力 **「繰り返しの結果」**、区切り **「新しい行」**
5. **「ファイルを保存」**: 保存先 `ショートカット/ypt-for-me`、名前 `categories.txt`、**「保存先を尋ねる」OFF**、**「上書き」ON**

**オンラインの状態で1回実行**してください。カテゴリを `/admin` で変えた時も、実行すれば更新されます。

## B-4. ショートカット「YPT オフライン対応」を作る

### ① 準備
1. 「ショートカットの入力」→「変数に設定」`タグ`
2. 「テキスト」`https://ypt-for-me.vercel.app` → 変数 `BASE`
3. 「テキスト」`Bearer ` + `API_SECRET` → 変数 `認証`
4. **「日付」→「日付をフォーマット」**: 形式 **「カスタム」**、`yyyyMMddHHmmssSSS` → 変数 `記録ID`
5. **「日付」→「日付をフォーマット」**: 形式 **「ISO 8601」** → 変数 `現在時刻`

### ② 開始か終了かを決める（サーバーに聞かない）
6. **「現在の集中モードを取得」**
7. **「もし」**: 集中モード **「が」「勉強」**

#### ▼ オン（勉強中）→ 終了の記録を保存
8. **「辞書」** を作る。項目は次のとおり（すべてテキスト）

| キー | 値 |
| :--- | :--- |
| `client_event_id` | `記録ID` |
| `type` | `stop` |
| `occurred_at` | `現在時刻` |

9. **「ファイルを保存」**: 保存先 `ショートカット/ypt-for-me/pending`、名前 `記録ID` + `.json`、**「保存先を尋ねる」OFF**
10. **「集中モードを設定」**: 「勉強」を **オフ**
11. **「通知を表示」**: `終了を記録しました`

#### ▼ 「そうでなければ」→ 開始の記録を保存
12. **「ファイルを取得」**: `ショートカット/ypt-for-me/categories.txt` → **「テキストを分割」**（区切り: 新しい行）
13. **「リストから選択」** → 変数 `カテゴリ名`
14. **「現在地を取得」** → 「現在地の詳細を取得」で `緯度`・`経度` を変数に設定（Part A の 16〜18 と同じ）
15. **「辞書」** を作る

| キー | 型 | 値 |
| :--- | :--- | :--- |
| `client_event_id` | テキスト | `記録ID` |
| `type` | テキスト | `start` |
| `category_name` | テキスト | `カテゴリ名` |
| `tag_id` | テキスト | `タグ` |
| `latitude` | 数字 | `緯度` |
| `longitude` | 数字 | `経度` |
| `occurred_at` | テキスト | `現在時刻` |

16. **「ファイルを保存」**: 保存先 `ショートカット/ypt-for-me/pending`、名前 `記録ID` + `.json`、「保存先を尋ねる」OFF
17. **「集中モードを設定」**: 「勉強」を **オン**
18. **「通知を表示」**: `開始を記録しました：` + `カテゴリ名`
19. **「もし」を閉じる**

### ③ たまった記録をサーバーに送る
20. **「フォルダの内容を取得」**: `ショートカット/ypt-for-me/pending` → 変数 `未送信ファイル`
21. **「それぞれを繰り返す」**: 入力 `未送信ファイル` → 中で **「ファイルから辞書を取得」**（「入力から辞書を取得」）。繰り返しを閉じる → 結果が **「繰り返しの結果」**（記録のリスト）
22. **「URLの内容を取得」**
    - URL: `BASE` + `/api/study/sync`
    - 方法: `POST`、ヘッダ: `Authorization` = `認証`
    - 要求本文: **JSON**、フィールド `events`（**リスト**）に「繰り返しの結果」
23. **「辞書から値を取得」**: キー `processed_event_ids`
24. **「もし」**: 辞書の値 **「値を持っている」**
    - **「ファイルを削除」**: 入力 `未送信ファイル`（**「確認なしで削除」ON**）
    - **「ショートカットを実行」**: 「YPT カテゴリ更新」
25. **「もし」を閉じる**

> **電波がない時:** 手順 22 で通信に失敗してエラーが出ますが、記録は手順 9 / 16 で保存済みなので消えません。次にかざした時、③ で自動的にまとめて送られます。

## B-5. 動作確認

1. **機内モードを ON** にして、「YPT オフライン対応」を▶実行 → 「開始を記録しました」が出る（通信エラーのメッセージが出てもOK）
2. 「ファイル」アプリで `ypt-for-me/pending` に `.json` ができている
3. **機内モードを OFF** にして、もう一度▶実行（= 終了）→ `pending` が空になる
4. https://ypt-for-me.vercel.app で、開始・終了の両方が記録されている

## B-6. 注意点

- **集中モードを手で切り替えると**、開始 / 終了の判定がずれます（サーバーの状態ではなく、集中モードで判断するため）。ずれたら `/admin` の Sessions で直せます。
- **古い記録の天気**: 30分より前の記録を後から送ると、天気は付きません（仕様です）。
- **カテゴリ名が `/admin` に存在しない**記録は、送信時にエラーとなり、**ファイルごと削除されます**（Sessions に出ません）。カテゴリを変えたら「YPT カテゴリ更新」を実行してください。
- 開始中に別の開始記録が送られると、前の記録が自動で閉じられ、**「要確認」** が付きます。`/admin` の Control で確認できます。

## 困った時

| 症状 | 対処 |
| :--- | :--- |
| `Unauthorized` / 401 | `Authorization` が `Bearer ` + `API_SECRET` か確認（半角スペース、余計な空白） |
| 「No category available」/ 409 | `/admin` の Categories でカテゴリを1つ作る |
| 400 エラー | 本文の型違い。`latitude` / `longitude` は「数字」、他は「テキスト」 |
| かざしても動かない | 画面が消えている。サイドボタンで点灯してからかざす |
| 金属に貼ったら反応しない | 金属対応（アンチメタル）の NTAG215 シールを使う |
| 位置情報が取れない | 設定で「ショートカット」の位置情報を許可する（A-0 参照） |
| 「値を持っている」が選べない | 「もし」の条件の一覧から、空かどうかを判定する項目を探す |
