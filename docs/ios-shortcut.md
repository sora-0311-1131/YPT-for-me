# iOS ショートカット設定ガイド（YPT for me）

NFC タグに iPhone をかざすと、**勉強の開始 / 終了が記録される**ようにする手順です。

## 全体像

```
NFCタグにかざす
  └→ オートメーション が起動
       └→ ショートカット「YPT」を実行
            ├─ サーバーに「今、勉強中？」と聞く（status）
            ├─ 勉強中じゃない → カテゴリを選ぶ → 開始（start）
            └─ 勉強中 → 終了（stop）
```

**まず「基本版」（Part 1〜3）だけ作ってください。** 電波がない時の保存機能（Part 4）は、基本版が動いてから足せば十分です。

---

## Part 0. 用意するもの（先に確認）

| 名前 | 値 | 入手元 |
| :--- | :--- | :--- |
| `BASE_URL` | `https://ypt-for-me.vercel.app` | 本番URL |
| `API_SECRET` | あなたが Vercel に登録した文字列 | パスワードマネージャーなど |

### 動作テスト（ショートカットを作る前に、PCで確認）

`API_SECRET` が正しいか、PowerShell で確かめます。`ここにAPI_SECRET` を自分の値に置き換えてください。

```powershell
Invoke-RestMethod -Uri "https://ypt-for-me.vercel.app/api/study/status" -Headers @{ Authorization = "Bearer ここにAPI_SECRET" }
```

`is_active : False` と `categories` が出れば OK です。`Unauthorized` と出たら `API_SECRET` が違います。

## Part 1. ショートカット「YPT」を作る（基本版）

`ショートカット` アプリ → 右上 `＋` → 名前を **「YPT」** にします。
下の **ステップ 1〜12 を上から順に** 追加してください。アクション名は iOS の日本語表記です（検索窓で名前を入れると出ます）。

### 1. 入力を受け取る準備
1. **`テキスト`** を追加し、`ショートカットの入力` を入れる（タグ名がここに入る）。名前（変数）を **`タグ名`** にする。

### 2. 勉強中かどうかを聞く
2. **`URLの内容を取得`**
   - URL: `https://ypt-for-me.vercel.app/api/study/status`
   - 方法: `GET`
   - ヘッダ: 追加 → キー `Authorization` / 値 `Bearer ` の後ろに API_SECRET
3. **`辞書から値を取得`**: `URLの内容` から キー **`is_active`** を取得。

### 3. 分岐
4. **`もし`**: 手順 3 の結果 **`is`** **`はい`**（= 勉強中なら終了）。

#### ▼ 勉強中だった場合（終了処理）
5. **`URLの内容を取得`**
   - URL: `https://ypt-for-me.vercel.app/api/study/stop`
   - 方法: `POST`
   - ヘッダ: `Authorization` = `Bearer API_SECRET`
   - 本文は空でOK
6. **`辞書から値を取得`**: キー `duration_min`（今回の分数）
7. **`通知を表示`**: `お疲れ様！ {duration_min} 分集中しました`
8. **`集中モードを設定`**: 「勉強」を **オフ**

#### ▼ `そうでなければ`（開始処理）
9. 手順 2 の `URLの内容` から、**`辞書から値を取得`** でキー **`categories`** を取得。
   さらに **`リストから選択`** を追加し、入力に `categories` を渡す。
   > 表示名を `name` にしたい場合は、先に `辞書から値を取得`（キー `name`）を `繰り返す` で回してリスト化します。まず動かすだけなら、辞書のまま選ばせて **`辞書から値を取得` → `id`** でも構いません。
10. 選んだカテゴリの **`id`** を `辞書から値を取得` で取り出す（変数名 **`カテゴリID`**）。
11. **`現在地を取得`**（位置情報の許可は「常に許可」が安定）。
    → 続けて **`詳細を取得`** で `緯度` と `経度` を取り出す。
12. **`URLの内容を取得`**
    - URL: `https://ypt-for-me.vercel.app/api/study/start`
    - 方法: `POST`
    - ヘッダ: `Authorization` = `Bearer API_SECRET`
    - 本文: `JSON`（追加するキーは下表）

| キー | 型 | 値 |
| :--- | :--- | :--- |
| `category_id` | テキスト | `カテゴリID` |
| `tag_id` | テキスト | `タグ名` |
| `latitude` | 数字 | 緯度 |
| `longitude` | 数字 | 経度 |

13. **`集中モードを設定`**: 「勉強」を **オン**（オフにするまで）
14. 最後に `もし` を閉じる（`End If`）。

### Part 1 の確認
ショートカット画面で▶を押して、実行できれば成功です。

- 1回目: カテゴリ選択 → 開始される
- もう一度: 終了されて「お疲れ様」の通知が出る

結果は https://ypt-for-me.vercel.app の画面にも出ます。

## Part 2. NFC タグを登録する

1. `ショートカット` アプリ → 下の `オートメーション` → `＋` → **`NFC`**
2. `スキャン` を押して、タグ（シール / ICOCA）に iPhone の上部をかざし、名前を付ける（例: `PCパームレスト`）
3. `次へ` → アクションに **`ショートカットを実行`** を追加
   - ショートカット: **YPT**
   - 入力: **`テキスト`** で `pc_palmrest`（ICOCA は `icoca_main`）
4. **「即座に実行」を ON** / **「実行時に通知」を OFF**

## Part 3. 使い方

| 状況 | やること |
| :--- | :--- |
| 開始 | タグにかざす → カテゴリを1回タップ |
| 終了 | タグにかざす（質問なし） |

> **ポイント:** 画面が真っ暗だと NFC が反応しません。サイドボタンを1回押して画面を点けてからかざしてください（ロック解除は不要）。

## Part 4. （任意）電波がない時の保存機能

地下などで通信できない時に、後から自動で送る機能です。**基本版が動いてから**で大丈夫です。
仕組みは「通信失敗 → iCloud のファイルに記録 → 次に通信できた時にまとめて送信」です。

1. iCloud Drive の `Shortcuts/ypt-for-me/pending_events.json` に、未送信の記録を配列で保存する。
2. 記録の形式（1件）:

   ```json
   {
     "client_event_id": "固有のID（日時の文字列など）",
     "type": "start",
     "category_id": "カテゴリID",
     "tag_id": "pc_palmrest",
     "latitude": 35.0262,
     "longitude": 135.7808,
     "occurred_at": "2026-11-25T13:00:00+09:00"
   }
   ```

   `type` は `start` か `stop`。`stop` の場合は `category_id` と座標は不要です。
3. ショートカットの最初で、このファイルが空でなければ `POST /api/study/sync` に送る。

   - URL: `https://ypt-for-me.vercel.app/api/study/sync`
   - ヘッダ: `Authorization: Bearer API_SECRET`
   - 本文: `{ "events": [ ...記録の配列... ] }`
4. 返事の `processed_event_ids` に入っていた記録だけをファイルから削除する。

## 困った時

| 症状 | 原因と対処 |
| :--- | :--- |
| `Unauthorized`（401） | `Authorization` ヘッダの `Bearer ` の後ろが `API_SECRET` と違う。`Bearer` の後ろに**半角スペース**が必要 |
| 400 エラー | 本文の型違い。`latitude` / `longitude` は「数字」、他は「テキスト」にする |
| かざしても動かない | 画面が消えている。サイドボタンで点灯してからかざす |
| 金属に貼ったら反応しない | 金属対応（アンチメタル）の NTAG215 シールを使う |
| 位置情報が取れない | `設定` → `ショートカット` → 位置情報を「常に許可」にする |
