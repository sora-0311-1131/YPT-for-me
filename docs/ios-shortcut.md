# iOS ショートカット設定ガイド（YPT for me）

NFC タグに iPhone をかざすと、**勉強の開始 / 終了が記録される**ようにする手順書です。
ショートカットを触ったことがなくても作れるように、**3段階**に分けています。

| 段階 | できること | 難易度 |
| :--- | :--- | :--- |
| **基本版**（Step 0〜2） | かざすと開始 / 終了。カテゴリは前回と同じ | ★ アクション3個 |
| **完全版**（Part A） | ＋ カテゴリを選べる / 場所を記録 / 集中モード連動 | ★★ |
| **オフライン対応**（Part B） | ＋ 電波がなくても記録して、あとで自動送信 | ★★★ |

**基本版が動いてから**、次の段階に進んでください。段階ごとに別のショートカットとして作り、動作確認してから NFC オートメーションの呼び出し先を切り替えるのが安全です。

> [!IMPORTANT]
> **URL やテキストに「余計なスペース・改行」を入れないでください。**
> 特に `[BASE]/api/...` の `[BASE]` と `/api` の間に半角スペースや改行が入ると、サーバーが HTML を返して「リッチテキストを辞書に変換できなかった」エラーになります。

## Step 0. 用意するもの

| 名前 | 値 | 入手元 |
| :--- | :--- | :--- |
| ベースURL | `https://ypt-for-me.vercel.app` | 本番URL |
| `API_SECRET` | あなたが Vercel に登録した文字列 | パスワードマネージャーなど |

### （任意）PC で先に動作テスト

PowerShell で次を実行します（`ここにAPI_SECRET` を自分の値に置き換え）。

```powershell
Invoke-RestMethod -Method Post -Uri "https://ypt-for-me.vercel.app/api/study/toggle" -Headers @{ Authorization = "Bearer ここにAPI_SECRET" }
```

`message : 開始しました：...` と出れば成功です。**実際に開始されるので、もう一度実行して終了してください。**

## Step 1. 基本版ショートカット「YPT」を作る（アクション3個）

1. **「ショートカット」アプリ** → 下のタブ「ショートカット」 → 右上 **「＋」**
2. 画面上部の名前を押して **「YPT」** に変更

### アクション 1：URLの内容を取得
1. 「アクションを検索」に `URL` → **「URLの内容を取得」**
2. 青い「URL」を押して `https://ypt-for-me.vercel.app/api/study/toggle` を入力
3. 「**›**」（矢印）で詳細を開き、**方法** を **`POST`** に変更
4. **ヘッダ** → **「新規ヘッダを追加」**
   - キー: `Authorization`
   - テキスト: `Bearer ` + あなたの `API_SECRET`（**`Bearer` の後ろに半角スペース**）

### アクション 2：辞書から値を取得
1. 検索で `辞書` → **「辞書から値を取得」**
2. 「辞書」が **「URLの内容」** になっていることを確認
3. 「キー」に `message` と入力

### アクション 3：通知を表示
1. 検索で `通知` → **「通知を表示」**
2. 本文が **「辞書の値」** になっていることを確認

▶ を押して、1回目は「開始しました」、2回目は「お疲れ様！…」と出れば成功です。

---

## Step 2. NFC タグに割り当てる

1. 下のタブ **「オートメーション」** → 右上 **「＋」** → **「NFC」**
2. **「スキャン」** を押し、タグに iPhone の上部をかざす
3. 名前を付ける（例: `PCパームレスト`）→ **「OK」** → **「次へ」**
4. **「新規の空のオートメーション」** → **「ショートカットを実行」** を追加
5. 青い「ショートカット」を押して **「YPT」** を選ぶ
6. **「次へ」** → **「実行前に確認」を OFF**（「即座に実行」）→ **「完了」**

> **ポイント:** 画面が真っ暗だと NFC が反応しません。サイドボタンを1回押して画面を点けてからかざしてください（ロック解除は不要）。

# Part A. 完全版（カテゴリ選択・場所・集中モード）

## A-0. 事前準備

1. **集中モードを用意する**（例：名前を **`作業`** や **`勉強`** にする。ここでは **`作業`** として説明します）
   `設定` → `集中モード` → `＋` → `カスタム`
2. **位置情報の許可**
   `設定` → `プライバシーとセキュリティ` → `位置情報サービス` → `ショートカット` → **「Appの使用中は許可」** 以上（正確な位置情報も ON）

## A-1. 流れ（全体像）

```
タグにかざす
 ├─ ① 準備：タグ名・ベースURL・認証を変数に入れる
 ├─ ② サーバーに状態を聞く（/api/study/status）
 └─ ③ もし active_session が「任意の値」なら（= 勉強中）
      ├─ はい → 終了（/api/study/toggle）→ 通知 → 作業をオフ
      └─ その他の場合 → カテゴリ選択 → 現在地取得 → 開始（/api/study/start）→ 通知 → 作業をオン
```

# Part B. オフライン対応（電波がなくても記録する）

## B-1. 考え方

iOS のショートカットには「通信エラーを受け止める」機能がないため、次の順番にします。

```
かざす
 1. まず iPhone の中に「記録」をファイルとして保存（電波不要）
 2. そのあと、たまっている記録をまとめてサーバーに送信（/api/study/sync）
     └ 電波がなくて失敗しても、記録ファイルは残る → 次回にまとめて送信
```

- 開始か終了かは、**iPhone の集中モード「作業」がオンかどうか**で決めます（サーバーに聞かないため）
- 記録 1 件 = ファイル 1 個。送信に成功したら、そのファイルを削除します

## B-2. 準備（1回だけ：フォルダを2つ作る）

「ファイル」アプリで **iCloud Drive → ショートカット**（または **この iPhone 内**）の中に、次のフォルダを作ります。

- `ypt-for-me`
- その中に `pending`

（例：`ショートカット / ypt-for-me / pending`）

## B-3. 小さなショートカット「YPT カテゴリ更新」を作る（5アクション）

オフラインでもカテゴリを選べるように、カテゴリ名を `categories.txt` に保存しておきます。

1. **「URLの内容を取得」**:
   - URL：`https://ypt-for-me.vercel.app/api/study/status`
   - 方法：`GET`
   - ヘッダ：`Authorization` ＝ `Bearer ` + `API_SECRET`
2. **「辞書から値を取得」**: `URLの内容` 内の **`categories`**
3. **「それぞれを繰り返す」**:
   - **`繰り返しの終了` の上（中）** に **「辞書から値を取得」**: **`[繰り返し項目]`** 内の **`name`**
4. **「テキストを結合」**（**`繰り返しの終了` の下** に置く！）:
   - 入力：**`[繰り返しの結果]`**、結合方法：**`改行`**
5. **「ファイルを保存」**（**`繰り返しの終了` の下** に置く！）:
   - 入力：**`[結合済みのテキスト]`**
   - 保存先：**`ypt-for-me`** フォルダ
   - **`›`** を開いて設定：
     - **保存先を尋ねる**：**OFF**
     - **サブパス**：`categories.txt`
     - **存在する場合は上書き**：**ON**

**オンライン＆勉強していない状態で1回 ▶ 実行**し、`categories.txt` に全カテゴリ名が入っていることを確認します。

## B-4. 本体ショートカット「YPTオフライン対応」を作る

新しいショートカットを作り、名前を **「YPTオフライン対応」** にします。以下の **【1/3】【2/3】【3/3】** を上から順に組んでください。

### 【1/3】仕込み ＆ 終了記録の保存

#### ① 準備
1. **「テキスト」** `pc_palmrest` → **「変数に設定」** `タグ`
2. **「テキスト」** `https://ypt-for-me.vercel.app` → **「変数に設定」** `BASE`
3. **「テキスト」** `Bearer ` + `API_SECRET` → **「変数に設定」** `認証`
4. **「日付」**（現在の日付）→ **「日付をフォーマット」**（`›` → 日付フォーマット：**`カスタム`**、フォーマット文字列：**`yyyyMMddHHmmssSSS`**）→ **「変数に設定」** `記録ID`
5. **「日付」**（現在の日付）→ **「日付をフォーマット」**（`›` → 日付フォーマット：**`ISO 8601`**）→ **「変数に設定」** `現在時刻`

#### ② 集中モードで「開始」か「終了」か判定する
6. **「現在の集中モードを取得」**
7. **「もし」**: **`[現在の集中モード]`** をタップして **`名前`** を選び、**`が`** **`作業`** の場合
   > ※他の集中モードを使っていない場合は `任意の値` でも代用できます。

#### ▼ `もし` 〜 `その他の場合` の間（= 勉強中なので終了を記録）
8. **「辞書」** を追加 → 「新規項目を追加」で **3つ**（すべて **テキスト**）：
   - `client_event_id`：`[記録ID]`
   - `type`：`stop`
   - `occurred_at`：`[現在時刻]`
9. **「ファイルを保存」** → `›` を開いて設定：
   - **保存先を尋ねる**：**OFF**
   - 保存先フォルダ：**`pending`** フォルダ
   - **サブパス**：`[記録ID].json`
10. **「集中モードを設定」**: **`作業`** を **オフ** に変更
11. **「通知を表示」**: `終了を記録しました`

---

### 【2/3】開始記録の保存（`その他の場合` 〜 `If 文の終了` の間）

12. **「ファイル」**（検索：`ファイル`、または「フォルダからファイルを取得」）: さっき作った **`categories.txt`** を選ぶ
13. **「テキストを分割」**: **`[ファイル]`** を **`改行`** で分割
14. **「リストから選択」**: 入力は **`[分割されたテキスト]`** → **「変数に設定」** `カテゴリ名`
15. **「現在の位置情報を取得」**（`›` → 精度を **`100メートル`** にすると室内でも 0.5 秒ほどで高速取得できます）→ **「変数に設定」** `現在地`
16. **「場所の詳細を取得」**: **`[現在地]`** の **`緯度`** → **「変数に設定」** `緯度`
17. **「場所の詳細を取得」**: **`[現在地]`**（`緯度` になっていたら `現在地` に戻す）の **`経度`** → **「変数に設定」** `経度`
18. **「辞書」** を追加 → 「新規項目を追加」で **7つ**：

| キー | 型 | 値 |
| :--- | :--- | :--- |
| `client_event_id` | テキスト | `[記録ID]` |
| `type` | テキスト | `start` |
| `category_name` | テキスト | `[カテゴリ名]` |
| `tag_id` | テキスト | `[タグ]` |
| `latitude` | **数字** | `[緯度]` |
| `longitude` | **数字** | `[経度]` |
| `occurred_at` | テキスト | `[現在時刻]` |

19. **「ファイルを保存」** → `›` を開いて設定：
    - **保存先を尋ねる**：**OFF**
    - 保存先フォルダ：**`pending`** フォルダ
    - **サブパス**：`[記録ID].json`
20. **「集中モードを設定」**: **`作業`** を **オン**（**`オフにするまで`**）
21. **「通知を表示」**: `開始を記録しました：` + `[カテゴリ名]`
22. **`If 文の終了`**

---

### 【3/3】たまった記録をサーバーに送る（`If 文の終了` の下）

23. **「フォルダの内容を取得」**: **`pending`** フォルダを選ぶ → **「変数に設定」** `未送信ファイル`
24. **「それぞれを繰り返す」**: **`[未送信ファイル]`** の各項目を繰り返す
    - **`繰り返しの終了` の上（中）** に **「辞書」**（検索：`入力から辞書を取得`）：入力 **`[繰り返し項目]`**
25. **「URLの内容を取得」** の前に、送信用の JSON 文字列を作る（`繰り返しの終了` の **下** に置く！）
    1. **「テキストを結合」**: 入力 **`[繰り返しの結果]`**、結合方法 **`カスタム`**、区切り **`,`**（半角カンマ1文字）
    2. **「テキスト」**: `{"events":[` + **`[結合済みのテキスト]`** + `]}`（※ **`+` やスペースは書かず**、`{"events":[[結合済みのテキスト]]}` のようにピタッとつなぐ）→ **「変数に設定」** `送信データ`
    3. **「URLの内容を取得」**:
       - URL：`[BASE]/api/study/sync`
       - 方法：`POST`
       - ヘッダ（2つ）：
         - キー **`Authorization`** ／ テキスト **`[認証]`**
         - キー **`Content-Type`** ／ テキスト **`application/json`**
       - 本文を要求：**`ファイル`** → ファイル：**`[送信データ]`**
26. **「辞書から値を取得」**: `URLの内容` 内の **`processed_event_ids`**
27. **「もし」**: **`[辞書の値]`** **`[任意の値]`** の場合
    - **「ファイルを削除」**: 入力 **`[未送信ファイル]`**（`›` → **「すぐに削除」** / 確認なしで削除 ON）
    - **「ショートカットを実行」**: **`YPT カテゴリ更新`**
28. **`If 文の終了`**

> **電波がない時:** 手順 25 で通信に失敗してエラーが出ますが、記録は手順 9 / 19 で保存済みなので消えません。次にかざした時、手順 23〜28 で自動的にまとめて送られます。

## B-5. 動作確認

1. **機内モードを ON** にして、「YPTオフライン対応」を ▶ 実行 → 「開始を記録しました」が出る（通信エラーのダイアログが出てもOK）
2. 「ファイル」アプリで `ypt-for-me/pending` に `.json` ができている
3. **機内モードを OFF** にして、もう一度 ▶ 実行（= 終了）→ `pending` フォルダが空になる
4. https://ypt-for-me.vercel.app で、開始・終了の両方が記録されている

## B-6. 注意点（普段の運用）

- **普段使うのは「YPTオフライン対応」の1本だけ**で、オンライン時もオフライン時も両方カバーできます。「YPT カテゴリ更新」は終了時（手順 27）に自動で実行されます。
- **集中モードを手で切り替えると**、開始 / 終了の判定がずれます。ずれたら `/admin` の Sessions で直せます。
- **古い記録の天気**: 30分より前の記録を後から送ると、天気は付きません（仕様です）。
- **カテゴリ名が `/admin` に存在しない**記録は、送信時にエラーとなり、**ファイルごと削除されます**（Sessions に出ません）。カテゴリを変えたら「YPT カテゴリ更新」を実行してください。
- 開始中に別の開始記録が送られると、前の記録が自動で閉じられ、**「要確認」** が付きます。`/admin` の Control で確認できます。

## カスタマイズしたいときの手法

運用しながら変えたくなった時は、目的に応じて以下の場所を触ります。

### 1. NFC タグを増やす（ICOCA・自宅机・大学など）
- **簡単な方法**: 「YPTオフライン対応」を長押し → **「複製」** して、手順 1 の `タグ` テキスト（例：`icoca_main`）だけ書き換えて、新しい NFC オートメーションから呼び出す。
- **1本で使い回す方法**: 手順 1 を「ショートカットの入力」に戻し、各 NFC オートメーション側で「テキスト（タグ名）」→「ショートカットを実行（入力にテキストを渡す）」を組む。

### 2. 集中モードの名前を変える / 集中モードと連動させない
- **別の集中モード名に変える**: 手順 7・10・20 の `作業` を、使いたい集中モード名に変更する。
- **集中モードと連動させたくない**: オフライン版は集中モードの状態で開始/終了を判定しているため、連動を外したい場合は **Part A（サーバーに聞くオンライン版）** を使うか、集中モードの代わりに iPhone 内の状態ファイルで ON/OFF を管理する形に書き換えます。

### 3. 開始時の「現在地取得」をもっと速くする / 省略する
- **さらに速くする**: 手順 15 の精度を **`1キロメートル`** に下げる（広いエリア判定向け）。
- **固定の場所専用にする（0秒）**: 自宅の PC パームレスト専用タグなら、手順 15〜17 を削除し、手順 18 の `latitude` / `longitude` に自宅の緯度・経度を数字で直接書くと GPS 待ちがゼロになります。

### 4. カテゴリ・時限・目標時間・日付境界（午前4時など）を変える
- ショートカットの編集は不要です。**`/admin`** の **Categories** / **Settings** タブから変更できます。
- カテゴリを追加・名前変更した直後だけ、**「YPT カテゴリ更新」** を1回 ▶ 実行するとすぐ `categories.txt` に反映されます。

### 5. スポット（場所）の追加・判定半径の調整
- **`/admin`** の **Spots** タブから編集できます。未登録座標からの1クリック登録や、過去の記録への一括再適用も可能です。
- 判定半径は **自宅 `100〜150m` / 建物 `80〜150m` / 大学全体 `500〜800m`** が目安です（円が重なっても **一番小さい半径のスポット** が自動で優先されます）。

### 6. アプリ本体の機能・グラフ・デザインを変える
- リポジトリの [spec.md](spec.md) や `src/` を編集して GitHub の `main` にマージすると、Vercel が自動で本番デプロイします。

## 困った時

| 症状 | 対処 |
| :--- | :--- |
| `Unauthorized` / 401 | `Authorization` が `Bearer ` + `API_SECRET` か確認（半角スペース、余計な空白） |
| リッチテキストを辞書に変換できなかった | URL の `[BASE]` の後ろや途中に**スペースや改行**が入っている |
| 「No category available」/ 409 | `/admin` の Categories でカテゴリを1つ作る |
| 400 エラー | 本文の型違い。`latitude` / `longitude` は「数字」、他は「テキスト」 |
| かざしても動かない | 画面が消えている。サイドボタンで点灯してからかざす |
| 金属に貼ったら反応しない | 金属対応（アンチメタル）の NTAG215 シールを使う |
| 位置情報が取れない | 設定で「ショートカット」の位置情報を許可する（A-0 参照） |
