# iOS ショートカット設定ガイド（YPT for me）

NFC タグに iPhone をかざすと、**勉強の開始 / 終了が記録される**ようにする手順です。
ショートカットを触ったことがなくても、**アクション3個**で動きます。

## しくみ

タグにかざすたびに、サーバーが自動で切り替えます。

| 今の状態 | かざすと |
| :--- | :--- |
| 勉強していない | **開始**（カテゴリは前回と同じ。初回は先頭のカテゴリ） |
| 勉強中 | **終了**（「お疲れ様！○分集中しました」と通知） |

カテゴリを変えたい時は、`/admin` の Sessions タブで後から直せます。

---

## Step 0. 用意するもの

| 名前 | 値 |
| :--- | :--- |
| ベースURL | `https://ypt-for-me.vercel.app` |
| `API_SECRET` | あなたが Vercel に登録した文字列 |

### （任意）PC で先に動作テスト

PowerShell で次を実行します（`ここにAPI_SECRET` を自分の値に置き換え）。

```powershell
Invoke-RestMethod -Method Post -Uri "https://ypt-for-me.vercel.app/api/study/toggle" -Headers @{ Authorization = "Bearer ここにAPI_SECRET" }
```

`message : 開始しました：...` と出れば成功です。**実際に開始されるので、もう一度実行して終了してください。**
`Unauthorized` と出たら `API_SECRET` が違います。

## Step 1. ショートカットを作る（アクション3個）

1. iPhone の **「ショートカット」アプリ**を開く
2. 下のタブ **「ショートカット」** → 右上 **「＋」**
3. 画面上部の名前を押して **「YPT」** に変更

### アクション 1：URLの内容を取得
1. 「**アクションを検索**」に `URL` と入力 → **「URLの内容を取得」** をタップ
2. 青い「URL」の部分を押して、次を入力
   `https://ypt-for-me.vercel.app/api/study/toggle`
3. 「**›**」（矢印）を押して詳細を開く
4. **方法** を `GET` から **`POST`** に変更
5. **ヘッダ** → **「新規ヘッダを追加」** を押す
   - キー: `Authorization`
   - テキスト: `Bearer ` + あなたの `API_SECRET`（**`Bearer` の後ろに半角スペース**）

### アクション 2：辞書から値を取得
1. 検索で `辞書` と入力 → **「辞書から値を取得」** をタップ
2. 「**辞書**」の青い部分が **「URLの内容」** になっていればOK
3. 「**キー**」に `message` と入力

### アクション 3：通知を表示
1. 検索で `通知` と入力 → **「通知を表示」** をタップ
2. 本文が **「辞書の値」** になっていればOK
   （違う場合は本文を押して、変数から「辞書の値」を選ぶ）

### 動作確認
画面下の **▶（再生）** を押します。
- 1回目: 「開始しました：○○」の通知
- もう1回: 「お疲れ様！…」の通知

https://ypt-for-me.vercel.app の画面にも反映されます。

> 初めて実行する時、ネットワーク接続の許可を聞かれたら **「許可」** を選んでください。

---

## Step 2. NFC タグに割り当てる

1. 下のタブ **「オートメーション」** → 右上 **「＋」** → **「NFC」**
2. **「スキャン」** を押し、タグ（シール / ICOCA）に iPhone の上部をかざす
3. 名前を付ける（例: `PCパームレスト`）→ **「OK」** → **「次へ」**
4. **「新規の空のオートメーション」** → アクション検索で **「ショートカットを実行」** を追加
5. 青い「ショートカット」の部分を押して **「YPT」** を選ぶ
6. **「次へ」** → **「実行前に確認」を OFF**（「即座に実行」にする）→ **「完了」**

---

## 使い方

- **開始**: タグにかざす
- **終了**: もう一度かざす

> **ポイント:** 画面が真っ暗だと NFC が反応しません。サイドボタンを1回押して画面を点けてからかざしてください（ロック解除は不要）。

---

## 困った時

| 症状 | 対処 |
| :--- | :--- |
| `Unauthorized` / 401 | `Authorization` の値が `Bearer ` + `API_SECRET` になっているか確認（半角スペース、コピー時の余計な空白） |
| 「No category available」/ 409 | `/admin` の Categories でカテゴリを1つ作る |
| 通知が空になる | アクション2の「辞書」が「URLの内容」か、キーが `message` か確認 |
| かざしても動かない | 画面が消えている。サイドボタンで点灯してからかざす |
| 金属に貼ったら反応しない | 金属対応（アンチメタル）の NTAG215 シールを使う |

---

## あとから足せる機能（慣れてから）

- **カテゴリを毎回選ぶ**: `GET /api/study/status` の `categories` から選び、`/api/study/toggle?category_id=...` を呼ぶ
- **場所の記録・集中モード連動・オフライン保存**: `POST /api/study/start` / `stop` / `sync` を使います（仕様は [spec.md](spec.md) を参照）
